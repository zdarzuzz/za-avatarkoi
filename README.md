# За аватаркой

Интерактивный лонгрид о первом впечатлении. Читатель выбирает людей по коротким анкетам, смотрит один возможный эпизод знакомства с каждым (манга), читает главы о том, что мы достраиваем по карточке, и возвращается к своим решениям.

Автор — Дарья Зюзина. Дизайн — Figma-файл `oEoEN5CxftTMHekTa4hbSt`, фреймы MacBook Air 2–17.
Персонажи и сцены вымышлены.

Чистые HTML, CSS и JavaScript (ES-модули). Без сборки и зависимостей — работает на GitHub Pages, в том числе из подпапки (все пути относительные).

## Запуск локально

ES-модули не работают при открытии `index.html` двойным кликом (`file://`), нужен локальный сервер.

**VS Code:** установи расширение **Live Server** (Ritwick Dey) → открой папку проекта → правый клик по `index.html` → **Open with Live Server**.

**Без расширения:** в терминале VS Code (`Ctrl+\``) из корня проекта:

```bash
python3 -m http.server 8000
# или
npx serve .
```

и открой <http://localhost:8000>.

Прогресс хранится в `localStorage` под ключом `za-avatarkoi:state`. Чтобы начать с нуля: DevTools → Application → Local Storage → удалить ключ (или кнопка «Попробовать ещё раз» в финале — она начинает новое прохождение без повторной обложки).

## Публикация на GitHub Pages

Settings → Pages → Source: *Deploy from a branch* → ветка `main`, папка `/ (root)`. Ничего собирать не нужно.

## Логика

- **Ситуация** выбирается в начале прохождения из перемешанной очереди трёх контекстов и не меняется до конца прохождения (в том числе после обновления страницы). Новое прохождение берёт следующую из очереди; одинаковых подряд не бывает.
- **Анкеты** одинаковы во всех ситуациях. «Продолжить общение» → опрос о причине; «Пропустить» → сразу следующая анкета, без опроса. Повторные нажатия блокируются.
- **Данные раздельно:** `initial` (первый выбор, не меняется), `reasons`, `answers` (ответ после манги), `final` (явное решение на финале).
- **Итоговое решение по умолчанию:** «Да» → продолжить, «Нет» → отказаться, «Не знаю» → не выбрано, нет ответа → первый выбор. На финале можно менять свободно; повторное нажатие снимает выбор.
- **История** определяется парой `situationId + characterId`. Первый выбор и причина меняют только вступление и предисловие к комментарию; поступки в сцене одинаковы при любом выборе.

## Как редактировать контент

- **Анкеты:** `js/data/characters.js` — `bio`, `interests`, `portrait`. Положение портрета в овальной рамке — `profileImg` (проценты из Figma).
- **Ситуации:** `js/data/situations.js` — `title`, `description`, `storyTitle`.
- **Истории:** `js/data/stories.js`. У кадра: `scene` (описание), `bubbles` — реплики `b(текст, x, y, ширина, угол)` для персонажа и `you(...)` для читателя. `x`, `y`, ширина — проценты от кадра; угол `bl | br | tl | tr` — где у плашки «хвостик». После правок историй запусти `node tools/build-storyboards.mjs`, чтобы обновить `docs/`.
- **Статьи:** текст — в `index.html` (раздел `#articles`), примеры слайдера и карточки — `js/data/article-examples.js`.

## Как добавить кадры манги

1. Открой сценарий в `docs/storyboards/<ситуация>-<персонаж>.md` — там для каждого кадра описание, реплики, пропорции, рекомендуемый размер и промпт. Реплики на изображение не наносятся — они накладываются HTML-текстом.
2. Сохрани кадр по пути из сценария, например `assets/images/manga/trip/danya-1.webp`.
3. Впиши путь в `MANGA_READY` в `js/data/manga-manifest.js`.

Плейсхолдер уже занимает точный размер кадра, поэтому вёрстка не сдвинется. Изображение кадрируется по центру (`object-fit: cover`); если нужно другое кадрирование — добавь кадру `fit: { w, h, l, t }` в процентах, как у кадров из Figma.

## Иллюстрация блокнота

Иллюстрация лежит в `assets/images/illustrations/travel-notebook.webp` (+ `-sm` для телефона) и стоит прямо в разметке главы «Первое впечатление продолжается» в `index.html`.

## Шрифты

- Везде используется только **EB Garamond** (SIL OFL): 400 / 600 / 700, прямой и курсив, файлы лежат в `assets/fonts/`, подключение — `css/fonts.css`.

## Доступность

Настоящие `button`, видимый фокус, клавиатура (Tab, Enter, пробел, стрелки в опросе и слайдере), подписи для круглых кнопок, `aria-pressed` у выбранных состояний, реплики манги — текст. При `prefers-reduced-motion` сложные перемещения отключаются, весь контент и переходы сохраняются. Изображения манги грузятся отложенно, место под кадры зарезервировано.
